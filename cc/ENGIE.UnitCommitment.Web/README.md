## Start from terminal
To start please enter the following commands from your favorite terminal from this folder (cc folder) :

```
dotnet restore
dotnet build
dotnet run --project ENGIE.UnitCommitment.Web/ENGIE.UnitCommitment.Web.csproj 
```

## Start from an IDE
Alternatively you can navigate in your explorer and open the .slnx file in Visual Studio or Rider and hit the Run or Debug button
